Three ways to watch it run out.

Three genuinely different visual mechanisms for a countdown timer with overflow. All three count down from a target (e.g. 60s), pass zero, then continue into overflow (+seconds beyond target) styled in clay-deep. One number on screen per option — no dashboards.

Mechanism, not paint. Each option uses a different way to show progress — radial (ring), linear (liquid), lexical (typography). All three handle overflow by switching to --clay-deep and growing a secondary surface (inverted ring, rising tide from the right, growing +N above).
