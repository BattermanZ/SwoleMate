01 · DIAL

The heartbeat dial.

A single luminous ring you can read across the room. Editorial restraint: italic serif numeral at the center, breathing animation tied to the session, everything else recedes.

  • Hero — conic clay→gold→clay ring on --surface-deep, 2.4s breathe.
  • Center — Instrument Serif italic numeral, status dot above, target below.
  • Below — three understated stat cells, two-button CTA.
  • Tone — calm, refined, athleisure. Reads as a moment of focus.
"The dial is alive, but it doesn't shout."
Notes. All three use the existing tokens from docs/design-system.html (no new colors, no new fonts). The --surface-deep + clay/gold accents and the breathing ring pattern are already spec'd in the design system — these options compose them differently. Pick a direction and I'll port it back into SessionExercise.svelte and add a documented component entry to the design system.
